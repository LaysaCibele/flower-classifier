# 🌷 Flower Classifier

End-to-end flower classification system developed to integrate
software development, machine learning and data science concepts.

## About

This project combines a React frontend, REST API, machine learning
model, database, Docker and cloud deployment into a complete application.

## Technologies

- React
- JavaScript
- Python
- REST API
- Machine Learning
- SQL
- Docker
